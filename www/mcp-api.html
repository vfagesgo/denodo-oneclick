MCP & API Services

Denodo Platform also provides a large number of additional data access services.

VDP MCP

The Denodo MCP Server provides:

  • Read-only access to Denodo databases
  • MCP resources: a resource describing the complete metadata of the database, and individual resources for each view
  • MCP tools: semantic search for metadata retrieval, listing available views, retrieving view schemas, executing/validating VQL queries, dedicated query tools for tagged views (deprecated), and tag-based metadata visibility across databases

MCP Endpoint

/mcp/admin/mcp

AI-SDK MCP

Connect the AI-SDK as an MCP server (i.e. as tools) with your MCP-compatible client (Visual Studio Code, Claude Desktop, Cursor…) via remote MCP (HTTP).

AI-SDK MCP Endpoint

/aisdk/mcp

Sample Dynamic Client Registration (DCR)

{
  "servers": {
    "Denodo_AI_SDK_Remote": {
      "url": "<mcp_endpoint>",
      "headers": {
        "Authorization": "Basic YWRtaW46YWRtaW4="
      }
    }
  }
}

AI-SDK REST-API

Key features

  • Text-to-VQL: translates natural language questions into VQL, so AI agents can query Denodo directly without manual SQL/VQL coding.
  • Metadata Search (RAG): vectorizes and searches your technical/business metadata for instant semantic discovery of data assets.
  • DeepQuery Agent: a research agent that plans and executes multi-step tasks combining metadata discovery with live VQL data extraction.
  • Model & Vector Store Agnostic: configure and switch between LLMs and Vector Databases depending on performance/privacy needs.

GraphQL

Enables the execution of GraphQL queries against the Denodo virtual data model, allowing GraphQL-like queries on top of any data source.

Endpoint

/denodo-graphql-service/graphql/<database>/schema.json

VDP RESTful

An HTTP service that publishes the contents of the entire Virtual DataPort server.

Endpoint

/denodo-restfulws/<database>/schema.json

Examples

/denodo-restfulws/admin — list of views of database admin.
/denodo-restfulws/admin/views/customer — content of view customer of database admin.
/denodo-restfulws/admin/views/customer/1/orders — browses the mapping orders of the customer row whose primary key is 1.
/denodo-restfulws/OpenAPIv3/openapi.json — OpenAPI 3 document in JSON format.
/denodo-restfulws/OpenAPIv3/openapi.yaml?database=db1&database=db2&tag=tag1&tag=tag2 — OpenAPI 3 document in YAML for views in db1/db2 tagged tag1/tag2.

Access Through JDBC

Denodo provides a JDBC Type 4 driver implementing the main characteristics of the JDBC 4.1 API - platform independent.

Get the driver from The Denodo Community (free registration required), or from the Denodo Platform installation (<DENODO_HOME>/tools/client-drivers/jdbc/vdp-jdbcdriver-core/denodo-vdp-jdbcdriver.jar).

Driver Class Name

com.denodo.vdp.jdbc.Driver

Connection URL

jdbc:denodo://<hostname>[:<port>]/[<database>][?<paramName>=<paramValue>[&<paramName>=<paramValue>]*]

Access Through ODBC

Denodo provides an ODBC driver for Windows and Linux (source code available for other platforms), based on the ODBC PostgreSQL driver version 16.00.

Refer to the Denodo documentation for more information.
